# Gamexdrive — Tienda web

Tienda de figuras de anime, peluches, Funko Pop y gift cards. Pedidos por WhatsApp.

- `index.html` — la web completa (productos y configuración al inicio del script).
- `worker-tasa-bcv.js` — Cloudflare Worker que lee la tasa oficial del BCV (se publica aparte en Cloudflare, no en GitHub Pages).

Publicada con GitHub Pages: https://josecolinar.github.io/gamexdrive/
